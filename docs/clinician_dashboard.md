# ZENOVA Clinician Dashboard Subsystem Specification

## 1. Overview & Clinical Objectives

The **ZENOVA Clinician Dashboard** is an extensible, privacy-compliant clinical decision-support portal designed for licensed mental health clinicians, clinical supervisors, triage directors, and compliance auditors.

The dashboard aggregates multi-modal observations (text conversation, acoustic voice prosody, smartphone passive sensing, personalized baseline shifts) and AI pipeline predictions into real-time triage queues, longitudinal trajectories, and granular explainability cards.

### Clinical Non-Diagnosis Invariant

> [!IMPORTANT]
> **MANDATORY CLINICAL NOTICE**:
> Algorithmic predictions generated by ZENOVA represent statistical pattern proxies and interaction strategies. They **DO NOT** constitute psychiatric diagnoses, DSM-5 medical evaluations, or emergency dispatch directives. Professional clinical judgment always supersedes automated outputs.

### Module Extensibility (`DashboardModuleRegistry`)

The dashboard is designed with a pluggable module registry (`DashboardModuleRegistry`) so that new data sources (e.g., wearable EEG, genetic biomarkers, EHR records) can be integrated without redesigning the dashboard:

```python
from zenova.dashboard.registry import DashboardModuleRegistry
from zenova.schemas.dashboard import DashboardModuleDescriptor

registry = DashboardModuleRegistry()

# Register custom wearable sensor module
registry.register(DashboardModuleDescriptor(
    module_id="wearable_eeg_tracker",
    name="Wearable EEG Frontal Asymmetry",
    category="sensor",
    description="Real-time alpha-band frontal asymmetry tracking for emotional regulation.",
    version="1.0.0"
))
```

## 3. Core Dashboard Areas

### 3.1 Overview Area (`/api/v1/dashboard/overview`)
- **Active Alerts**: Live count of unresolved triage alerts (`pending`, `acknowledged`, `in_review`).
- **Severity Breakdown**: Counts categorized into `critical`, `high`, `medium`, and `low`.
- **Population Risk Trends**: Real-time distribution of risk levels (`no_risk`, `low`, `moderate`, `high`, `critical`) across recent interactions.
- **Recent Escalations**: Top 5 most recent escalation alerts with quick-action links.
- **System Health Status**: Active models, execution devices (CPU/GPU), database connection status.

### 3.2 Individual User Area (`/api/v1/dashboard/users/{user_id}/*`)
- **Patient Profile Summary**: Current triage risk level, baseline status (`insufficient_data`, `establishing_baseline`, `established_baseline`), baseline deviation z-score ($\sigma$), and open alerts.
- **Emotion Trajectory**: Turn-by-turn tracking of primary emotion, continuous valence ($-1.0$ to $+1.0$), and arousal ($0.0$ to $+1.0$).
- **Symptom Radar**: Detected psychological symptom signals (depressive symptoms, anxiety, sleep disturbances) and severity.
- **Support Strategy Distribution**: Proportions of ESConv emotional-support strategies applied (`Reflection of feelings`, `Affirmation and Reassurance`, `Providing Suggestions`, etc.).
- **Turn-by-Turn Conversations**: Chronological transcripts displaying user messages and assistant responses along with turn-level ML prediction badges.

### 3.3 Unified Longitudinal Timeline (`/api/v1/dashboard/users/{user_id}/timeline`)
Integrates all longitudinal events into a single, filterable chronological feed:
1. **Conversation Turns**: Chat messages with speaker and risk flags.
2. **Behavioral Observations**: Passive smartphone metrics (step counts, screen time, sleep duration proxies).
3. **Voice Acoustic Samples**: Vocal affect, acoustic emotion classification, duration, and confidence.
4. **Baseline Shifts**: Significant deviations from personalized rolling baseline ($\ge 2.0\sigma$).
5. **Escalation Triggers**: Critical crisis alerts and safety gate overrides.

### 3.4 ML Explainability Inspector (`/api/v1/dashboard/users/{user_id}/explainability`)
For every machine learning output in the ZENOVA pipeline, the inspector renders a dedicated transparency card:
- **Model Name & Version**: (e.g., `Multi-Task Crisis & Suicide Risk Transformer`, `risk-multitask-transformer-v1`).
- **Modality**: Text, speech audio, passive smartphone sensor, dialogue context.
- **Confidence Score**: Calibrated probability or model certainty.
- **Relevant Signals / Features**: Extracted token cues, pitch/jitter metrics, behavioral deltas.
- **Timestamp**: Exact inference time.
- **Clinical Limitations**: Algorithmic caveats and scope constraints.
- **Non-Diagnosis Notice**: Explicit banner affirming decision-support status.

## 4. Privacy, Security & Role-Based Access Control (RBAC)

Access permissions are enforced through `AccessControlManager`:

| Role | Access Dashboard | View Overview | View Transcripts & Unmasked IDs | View Audit Logs |
| :--- | :---: | :---: | :---: | :---: |
| `CLINICIAN` | **Yes** | **Yes** | **Yes** (Unmasked) | No |
| `TRIAGE_SUPERVISOR` | **Yes** | **Yes** | **Yes** (Unmasked) | **Yes** |
| `AUDITOR` | **Yes** | **Yes** | **No** (Masked `usr_***` & redacts text) | **Yes** |
| `SYSTEM_ADMIN` | **Yes** | **Yes** | **No** (Masked `usr_***` & redacts text) | **Yes** |
| `PATIENT` | **No** (403) | **No** (403) | **No** (403) | **No** (403) |

### PHI / PII Redaction
When non-clinician roles (`AUDITOR`, `SYSTEM_ADMIN`) query user endpoints:
- User IDs are masked: `patient_4892` $\rightarrow$ `usr_***4892`.
- Raw conversation turns are masked: `"I want to die"` $\rightarrow$ `"[CONFIDENTIAL_TRANSCRIPT_PROTECTED]"`.
- Trigger cues are masked: `["suicide plan"]` $\rightarrow$ `["[REDACTED_CONFIDENTIAL_CUE]"]`.

### Access Audit Logging (`dashboard_access_logs`)
Every dashboard access event is immutably logged with:
- `access_id`: Cryptographic identifier (e.g., `acc_39af824bc109`).
- `actor_id`: User ID of accessing clinician or auditor.
- `actor_role`: RBAC role.
- `target_user_id`: Target patient ID (if patient-specific data accessed).
- `endpoint`: API route accessed.
- `action`: High-level action type (`view_overview`, `view_patient_summary`, `view_timeline`, etc.).
- `ip_address`: Client IP address.
- `timestamp`: UTC timestamp.
